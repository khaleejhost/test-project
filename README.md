# Testing Project

A simple multi-page website built with pure HTML and CSS — no JavaScript, no frameworks.

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Landing page with hero section and feature cards |
| About | `about.html` | About the project |
| Services | `services.html` | Grid of service cards |
| Web Design | `web-design.html` | Full landing page: features, process, pricing, CTA |
| Contact | `contact.html` | Contact form |

## Features

- Responsive navbar with CSS-only hamburger menu (mobile)
- Services dropdown menu (pure CSS hover)
- Inter Tight font (Google Fonts)
- Red & dark blue color theme
- Responsive grids and layouts across all pages

## Usage

No build step needed — just open `index.html` in a browser.

```bash
# or serve locally
python -m http.server 8000
```
